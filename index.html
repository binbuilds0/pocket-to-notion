Turn your Pocket or Instapaper export into a CSV that Notion imports as a database, with Title, URL, Tags, Saved date and Status columns, plus a Markdown list of every link.

Your file never leaves your browser. The conversion runs on this page. Its Content-Security-Policy blocks every network request, so nothing can be uploaded, and it works offline.

Import the CSV into Notion

  1. Download the Notion CSV above.
  2. Import it. In Notion, open Settings → Import → CSV (or type /csv on a page) and upload the file. Each link becomes a page in a new database.
  3. Set property types. If Tags arrives as text, change it to Multi-select: the comma-separated values become separate tags. Set Saved date to Date and Status to Select if needed.
  4. Adding to an existing database? Open it, click ••• → Merge with CSV. Imports add rows and never update existing ones, so merge each file once.

Notion accepts CSV files up to 5 MB on the Free plan and 50 MB on paid plans. Larger libraries are split into parts automatically.
